# Included Semantic examples

These are real files from the Semantic VS Code extension rather than invented pseudocode.

- `semantic-graph.se`: graph-oriented program with origin, type table, nodes and relations.
- `native-sections.se`: native readable section projection with types, scopes, nodes, relations and facets.
- `readable-transport.sp`: readable versioned `.sp` transport sample.
- `highlighting-fixture.se`: lexical fixture containing null, booleans, numbers, references, lists, objects, ranges and relations.

The examples are intentionally small enough for a model to inspect completely.
