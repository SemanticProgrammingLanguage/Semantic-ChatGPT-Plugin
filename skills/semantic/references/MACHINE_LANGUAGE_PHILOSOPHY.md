# Machine-oriented Semantic philosophy

Semantic is intended to be a language for machines and program-transforming systems.

The design objective is:
- express meaning independently of source syntax,
- carry richer facts than any one target may support,
- preserve source semantics before lowering,
- allow direct generation by machine systems,
- enable language-to-language and language-to-native translation through one semantic center.

A model generating Semantic should ask:
"What does this program mean and require?"
before:
"How would language X spell this?"

Semantic is therefore not defined by the easiest target language. It should retain high-level and low-level semantics together where necessary.
